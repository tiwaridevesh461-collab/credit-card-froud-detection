# VaultGuard 🛡️

A modern, multi-functional financial security and expense tracking dashboard built in a single HTML file. 

## ✨ Key Features
* **Financial Dashboard:** Track income and expenses with interactive charts (Chart.js).
* **Secure Card Linking:** OTP-based verification flow to securely add new credit cards.
* **Fraud Protection Center:** Monitor AI-detected transaction anomalies, lock/unlock cards, and manage security alerts.
* **Tabbed Interface:** Fully working navigation switching seamlessly between Dashboard, Cards, and Security views.
* **Premium UI:** Designed with Tailwind CSS for a highly professional, responsive, and app-like experience.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Tailwind CSS via CDN), Vanilla JavaScript
* **Charts:** Chart.js (CDN)
* **Icons:** FontAwesome (CDN)

## 🚀 How to Run
1. Download the `index.html` file.
2. Double-click the file to open it in any modern web browser (Chrome, Edge, Safari, Firefox).
3. No local server, build steps, or dependencies required!

## 📁 Project Structure
The entire application (HTML structure, Tailwind styling classes, and JavaScript logic for tabs, modals, and charts) is completely self-contained within the single `index.html` file.
